# 健身新手 AI 助理

## 一、專題動機

我最近加入健身房，但還不熟悉器材的使用方式、
動作的主要訓練部位，以及如何安排健身課表。

教練可以提供相關指導，但教練課的費用對身為學生的我而言
負擔較大。因此，我希望透過 AI 人工智慧導論課程，
學習製作一個健身新手 AI 助理，提供容易理解、
有資料依據的健身入門資訊。

## 二、服務對象

剛加入健身房、不熟悉器材，而且預算有限的學生與健身初學者。

## 三、預計功能

### 1. 器材操作諮詢
根據器材名稱及型號，介紹用途、調整方式、基本操作步驟
與注意事項。資訊不足時，先向使用者詢問。

### 2. 動作與訓練肌群說明
說明動作的主要訓練肌群、動作提示與常見錯誤，
幫助使用者建立基本觀念。

### 3. 入門課表草案
先詢問使用者的健身目標、訓練經驗、每週可運動天數、
每次可用時間與可使用的器材，再提供課表草案。

## 四、使用場景

### 場景一：第一次使用器材
使用者詢問：「坐姿划船機是做什麼的？使用前要調整什麼？」

助理先確認器材，再依據對應的操作資料，
提供用途、調整方式及操作注意事項，並附上資料來源。

### 場景二：了解動作主要訓練哪裡
使用者詢問：「這個動作主要練哪個部位？」

助理說明主要訓練肌群與動作提示，
但不宣稱能僅靠文字確認使用者的姿勢與發力是否正確。

### 場景三：不知道怎麼安排訓練
使用者詢問：「我是新手，每週有三天可以去健身房，
可以怎麼安排？」

助理先詢問目標、經驗、時間及器材，
再提供可進一步確認與調整的入門課表草案。

## 五、初期實作範圍

第一版預計先整理三種健身器材的文字問答，
練習讓 AI 根據提供的資料回答問題。

後續再配合課程進度，逐步加入使用者偏好記憶、
知識庫、工作流與課表安排功能。

## 六、預計資料來源

- 器材製造商的官方操作手冊。
- 可信運動專業機構提供的教學資料。

使用資料時會記錄來源、日期與適用器材。
目前尚未完成資料蒐集。

## 七、功能限制

- 無法僅靠文字確認使用者的姿勢、發力或操作是否正確。
- 不提供傷痛診斷與復健處方。
- 資料不足時先追問，找不到可靠依據時明確說明。
- 不取代現場教練的動作觀察與指導。
